# Wordlists de laboratório

Use somente listas pequenas, fictícias e criadas para o laboratório autorizado.

- Não utilizar senhas pessoais.
- Não utilizar credenciais corporativas.
- Não importar bases vazadas.
- Não publicar credenciais descobertas.
- Documentar a finalidade e o tamanho da lista utilizada.

O arquivo `exemplo-ficticio.txt` contém apenas valores ilustrativos e não representa uma lista real de credenciais.
